# JSON Protocol Specification

**Date:** 2026-06-20
**Direction:** PowerShell → Rust Engine (via stdin)
**Format:** Single-line JSON, one payload per execution

---

## SceneConfig Fields

| Field | Type | Required | Default | Description |
|-------|------|----------|---------|-------------|
| `effect` | string | **Yes** | — | Effect name to render |
| `cow_text` | string | **Yes** | — | Full ASCII cow art (with `\n` newlines) |
| `fps` | integer | No | `30` | Target frames per second (1–120) |
| `duration` | integer | No | `0` | Frame count limit. `0` = infinite loop |
| `background` | boolean | No | `false` | `true` = overlay mode (prompt-safe), `false` = full-screen |
| `overlay_height` | integer | No | `10` | Rows to reserve for overlay in background mode |

---

## Field Details

### `effect` (string, required)

Valid values:
```
"aurora"        "ember"         "shatter"       "plasma"
"liquid-chrome" "portal"        "glitch"        "neon-pulse"
"physics"       "static"        "breathing"     "liquid"
"sway"          "bounce"        "flying"        "fire"
"matrix"        "pulse"         "dissolve"      "random"
```

Case-sensitive. Unknown values default to `aurora`.

### `cow_text` (string, required)

The complete ASCII art output from `cowsay`. Newlines are escaped as `\n`. Double quotes escaped as `\"`.

Example raw cowsay output:
```
 _______
< Hello >
 -------
        \   ^__^
         \  (oo)\_______
            (__)\       )\/\
                ||----w |
                ||     ||
```

Encoded for JSON:
```
"cow_text": " _______\\n< Hello >\\n -------\\n        \\   ^__^\\n         \\  (oo)\\_______\\n            (__)\\       )\\/\\n                ||----w |\\n                ||     ||"
```

### `fps` (integer, optional)

- Range: `1` – `120`
- Values outside range clamped by `Scheduler::new()`
- Default: `30`
- Higher values = smoother animation, higher CPU usage

### `duration` (integer, optional)

- `0` = infinite loop (exit on keypress only)
- `N` = render exactly N frames, then exit
- Default: `0`

### `background` (boolean, optional)

- `false` = **Foreground mode**: full-screen, hides cursor, enters raw mode
- `true` = **Background mode**: overlay-only, cursor visible, prompt usable
- Default: `false`

### `overlay_height` (integer, optional)

- Only used when `background: true`
- Number of rows from top of terminal to allocate for overlay
- Clamped to `min(overlay_height, rows - 3)` — always leaves 3 rows for prompt
- Default: `10`

## Example Payloads

### Minimal (foreground, random effect)
```json
{"effect":"random","cow_text":" _________\n< Hello! >\n ---------\n        \\   ^__^\n         \\  (oo)\\_______\n            (__)\\       )\\/\\\n                ||----w |\n                ||     ||"}
```

### Full foreground with custom FPS
```json
{
  "effect": "ember",
  "cow_text": " _________\n< Fire! >\n ---------\n        \\   ^__^\n         \\  (oo)\\_______\n            (__)\\       )\\/\\\n                ||----w |\n                ||     ||",
  "fps": 60,
  "duration": 300,
  "background": false
}
```

### Background overlay mode
```json
{
  "effect": "aurora",
  "cow_text": " _________\n< BG Mode >\n ----------\n        \\   ^__^\n         \\  (oo)\\_______\n            (__)\\       )\\/\\\n                ||----w |\n                ||     ||",
  "fps": 30,
  "duration": 150,
  "background": true,
  "overlay_height": 12
}
```

### Daemon invocation (from PowerShell)
```powershell
$payload = @{
    effect   = "random"
    cow_text = $cowOutput   # output of cowsay
    background = $true
    duration = 150
} | ConvertTo-Json -Compress

$payload | & forgum-engine
```

### Shell hook (bash) — generated by `forgum-engine init bash`
```bash
forgum() {
    local config="~/.config/Forgum/config.json"
    local effect="random"
    if [ -f "$config" ]; then
        local parsed=$(grep -oE '"effect"\s*:\s*"[^"]+"' "$config" | cut -d'"' -f4)
        if [ ! -z "$parsed" ]; then
            effect="$parsed"
        fi
    fi
    local cow="$(cowsay "$@")"
    local json_cow="${cow//$'\n'/\\n}"
    json_cow="${json_cow//\"/\\\"}"
    echo "{\"effect\":\"$effect\",\"cow_text\":\"$json_cow\",\"background\":true,\"duration\":150}" | forgum-engine
}
```

## Error Handling

### Invalid JSON
```
Input: "not json"
 stderr: "Failed to parse config: expected value at line 1 column 1"
 exit: 0 (graceful)
```

### Missing Required Fields
```
Input: {"fps": 30}
 stderr: "Failed to parse config: missing field `effect`"
 exit: 0 (graceful)
```

### Empty Input
```
Input: "" (empty stdin)
 stderr: "No input provided. Pipe JSON config to stdin."
 exit: 0
```

### Unknown Effect Name
```
Input: {"effect": "typo", "cow_text": "..."}
 Behavior: Falls back to AuroraEffect (default)
 no stderr warning
```

### FPS Out of Range
```
Input: {"fps": 500, ...}
 Behavior: Clamped to 120 by Scheduler::new()
 no stderr warning
```

### Duration Overflow
```
Input: {"duration": 4294967295, ...}
 Behavior: Uses u32::MAX, effectively infinite
 no stderr warning
```

## Process Lifecycle

### Foreground Mode
```
1. Parent shell pipes JSON to forgum-engine stdin
2. Engine parses config, enters foreground render loop
3. Engine hides cursor, enters raw mode (via crossterm)
4. Animation runs until exit condition
5. Engine restores cursor, resets colors, exits
6. Shell prompt returns
```

### Background Mode
```
1. Parent shell pipes JSON to forgum-engine stdin
2. Engine parses config, sees background=true
3. Engine spawns detached child: forgum-engine --daemon
4. Child receives JSON via piped stdin
5. Parent exits immediately → shell prompt returns
6. Child runs overlay render loop independently
7. Child exits on keypress or duration exhaustion
8. Overlay region cleared, terminal restored
```

### Daemon Flag
```
forgum-engine --daemon
  - Reads JSON from stdin (same format)
  - Skips the spawn step (already detached)
  - Goes directly to render_loop_background()
```

## init Subcommand

```
forgum-engine init <shell>
```

| Shell | Output |
|-------|--------|
| `bash` | Bash function using `cowsay` + JSON pipe |
| `zsh` | Zsh function (same pattern) |
| `fish` | Fish function with `string collect` |
| `pwsh` | PowerShell function with `ConvertTo-Json` |
| other | Error message to stdout |

Generated hooks:
1. Read effect from `~/.config/Forgum/config.json`
2. Run `cowsay` with user arguments
3. Escape newlines and quotes in cow output
4. Pipe JSON payload to `forgum-engine`
